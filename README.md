# Curso AI Engineering

Repositorio personal donde documento y desarrollo las distintas entregas y proyectos realizados durante mi formación en **AI Engineering**.

El objetivo es aplicar progresivamente conceptos de Python, inteligencia artificial, integración con modelos de lenguaje (LLM), APIs y desarrollo de soluciones basadas en IA.

## Entregas

### Pre-entrega 1 — Async LLM Manager

Implementación de un administrador asíncrono de modelos de lenguaje, con integración de múltiples proveedores y generación de respuestas mediante streaming.

**Tecnologías:** Python, Asyncio, OpenAI, Anthropic, Pydantic.

[Ver proyecto y documentación](./Pre-entrega-1/README.md)
